## I. Information Architecture school (01-04)
> Philosophy: "Data is not decoration, it is building material."

### 01. Pentagram - Michael Bierut style
**Philosophy**: Type is language; the grid is thought.
**Key traits**:
- Extremely restrained color (black/white + one brand color)
- A modern take on the Swiss grid system
- Typography as the primary visual language
- Strategic use of negative space (60%+ whitespace)

**Prompt DNA**:
```
Pentagram/Michael Bierut style:
- Extreme typographic hierarchy, Helvetica/Univers family
- Swiss grid with precise mathematical spacing
- Black/white + one accent color (#HEX)
- Information architecture as visual structure
- 60%+ whitespace ratio
- Data visualization as primary decoration
```

**Flagship works**: Hillary Clinton 2016 campaign identity
**Search keywords**: pentagram hillary logo system

## How to use the prompt DNAs

**Combination formula**: `[style prompt DNA] + [scene template (see scene-templates.md)] + [specific content]`

### Core principle: describe Mood, Not Layout

The key to AI image generation: short prompts > long prompts. Three sentences about mood and content beat 30 lines of layout details.

| Variety-killing writing | Creativity-sparking writing |
|----------------|----------------|
| Specify color ratios (60%/25%/15%) | Describe a mood ("warm like Sunday morning") |
| Pin down layout positions ("title centered, image on the right") | Reference a specific aesthetic ("Pentagram editorial feel") |
| Lock down character poses and expressions | Let the AI interpret the style naturally |
| List every visual element that must appear | Describe what the viewer should feel |

### Good / Bad examples

**Bad - over-constrained (AI output ends up empty and flat):**
```
Professional presentation slide. Dark background, light text.
Title centered at top. Two columns below. Left column: bullet points.
Right column: bar chart. Colors: navy 60%, white 30%, gold 10%.
Font size: title 36pt, body 18pt. Margins: 40px all sides.
```

**Good - mood-driven (varied output with real texture):**
```
A data visualization that feels like a Bloomberg Businessweek
editorial spread. The key number "28.5%" should dominate the
composition like a headline. Warm cream tones with sharp black
typography. The data tells a story of dramatic channel shift.
```

### Choosing an execution path

Pick from the "Best path" column of the quick-reference table:
- **AI-generated**: styles with clear visual elements (06/07/12/13/14/15/16/20), generated directly via Gemini/Midjourney
- **HTML render**: styles that depend on precise typography (01/03/04/10/11/17/18), with code controlling data and layout
- **Hybrid**: HTML as skeleton layout + AI-generated imagery/backgrounds (02/05/08/09/19)

### Quality control

1. Don't write "in the style of Pentagram" outright -> use specific design traits instead
2. Text often comes out wrong in AI generation -> replace the text after generation
3. Proportions distort easily -> always specify the aspect ratio
4. Generate 3-5 variants first, then refine the best one

**Default aesthetic no-go zones** (users can override for their own brand):
- No cyber-neon / deep blue backgrounds (#0D1117)
- No personal signatures or watermarks on cover images
